# 中文 AI 数据标注与回答质量评估作品集

**作者：伍亚林**  
**作品类型：个人练习 / 示例作品**  
**目标任务：中文文本分类、内容审核、语义标注、语言模型回答质量评估、文本校对**

> 说明：本仓库中的案例均为本人制作的练习样例，不代表真实客户项目、商业交付、正式工作经历或付费任务。示例中的模型回答为模拟内容，用于展示评估方法。

## 1. 中文文本分类示例

| 编号 | 示例文本 | 标签 | 判断依据 |
|---|---|---|---|
| C001 | 请问这款耳机支持蓝牙连接吗？ | 商品咨询 | 询问商品功能信息 |
| C002 | 我付款后一直没有收到订单确认。 | 订单问题 | 涉及付款后的订单状态 |
| C003 | 这个教程讲得很清楚，步骤也容易跟着做。 | 正向评价 | 明确表达满意和认可 |
| C004 | 页面显示无法登录，重置密码也没有用。 | 技术故障 | 描述登录功能异常及已尝试的解决方法 |
| C005 | 请把“我们明天再讨论”翻译成英文。 | 翻译请求 | 明确要求进行语言转换 |

## 2. 内容审核与风险识别示例

| 编号 | 示例文本 | 处理建议 | 原因 |
|---|---|---|---|
| M001 | 这款产品效果很好，我很喜欢。 | 可通过 | 普通主观评价，无明显违规信息 |
| M002 | 点击不明链接并输入账号密码即可领取奖励。 | 标记复核 | 存在诱导访问不明链接并索取账号凭据的风险 |
| M003 | 这个观点我不同意，理由如下…… | 可通过或按上下文复核 | 单纯表达不同意见不等于违规，需要结合完整语境判断 |
| M004 | 文章中包含个人电话号码和家庭住址。 | 隐私信息复核 | 可能涉及个人敏感信息，应依据平台规则处理 |

**审核原则：** 不只凭关键词做结论；尽量结合上下文；证据不足时标记“需复核”，不把推测当作事实。

## 3. 模拟语言模型回答评估

**问题：** 用户问“如何安全地设置一个强密码？”

**模拟回答 A：** “使用较长且独特的密码，不要在多个网站重复使用；优先使用可信的密码管理器，并为重要账户启用多因素验证。”

- 相关性：高——直接回答了问题。
- 准确性：高——建议符合常见账户安全实践。
- 完整性：较高——覆盖密码长度、唯一性、管理器和多因素验证。
- 清晰度：高——表达简洁、可执行。
- 总评：优质回答；可补充警惕钓鱼网站，但不影响核心结论。

**模拟回答 B：** “所有网站都用同一个容易记住的密码就行。”

- 相关性：中——谈到了密码设置，但没有安全地解决问题。
- 准确性：低——重复使用密码会增加账户连带风险。
- 完整性：低——没有给出安全的设置方法。
- 清晰度：高——句子简单，但清晰不代表正确。
- 总评：不合格；主要问题是安全建议错误。

### 评估维度（每项 1–5 分）

| 维度 | 检查问题 |
|---|---|
| 相关性 | 是否直接回应用户问题？ |
| 准确性 | 是否有明显错误、无依据的断言或误导？ |
| 完整性 | 是否遗漏完成任务所必需的信息？ |
| 清晰度 | 是否易懂、结构合理、无歧义？ |
| 安全性 | 是否包含可能造成伤害、泄露隐私或鼓励不安全行为的建议？ |

## 4. 中文校对示例

**原句：** 由于系统出现了问题，所以导致用户不能够正常的进行登录。

**校对后：** 由于系统出现问题，用户无法正常登录。

**修改说明：** 删除重复表达；将“正常的”改为更自然的“正常”；压缩冗余结构；保留原句含义。

## 5. 质量检查流程

1. 先确认任务要求、标签定义和输出格式。
2. 阅读完整文本，结合上下文判断，不只依赖单个关键词。
3. 对每条结果检查标签是否一致、依据是否充分。
4. 对模糊、冲突或证据不足的案例标记“需复核”，不随意猜测。
5. 提交前检查遗漏、重复、错别字、格式和隐私信息。

## 6. 能力边界与真实性声明

本作品展示的是个人练习中使用的分类、审核、校对和回答评估方法。它不是客户交付物，也不声称具有正式标注项目经验、客户评价、商业收入或专业认证。实际工作将以雇主提供的标注规范、平台政策和验收标准为准。
